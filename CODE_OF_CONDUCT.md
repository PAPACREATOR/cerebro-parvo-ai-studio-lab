# Código de Conduta

Este projeto aceita crítica técnica forte, revisão adversarial e desacordo sobre arquitetura. Ataques pessoais, assédio, ameaças, discriminação, exposição de dados pessoais e spam não são aceitáveis.

Contribuições devem discutir comportamento, código, evidência e testes — não características pessoais do contribuidor.

O mantenedor pode editar, ocultar ou remover conteúdo abusivo e limitar participação quando necessário para proteger o projeto e os participantes.
